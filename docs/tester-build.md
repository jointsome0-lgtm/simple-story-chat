# Сборка тестера и следующий кандидат

Проверка хоста 1 октября 2026 года установила фактический источник бота тестера:
`live-pace@4febee6`, а не текущий checkout `codex/comfyui-integration@b877a84`.
Отдельно работает стенд Mini App только для владельца. У этих процессов разные Telegram-токены
и разные файлы баз; для проверки сравнивались только признаки, содержимое баз не читалось.

Числа, полные commit и fingerprint сохранены в
[снимке проверки](knowledge/tester-build-2026-10-01.json).
Это паспорт наблюдаемой сборки и состав будущего кандидата. Кандидат ещё не собран и не развёрнут.

## Наблюдаемые процессы

Процессы проверены на хосте в 15:05 по Москве; конфигурация восстановлена в 15:19.
Изолированная среда проверки видела только три процесса, поэтому её первый результат «ботов нет»
не использовался как состояние хоста.

| Назначение | Исходники | Начало процесса по Москве | Runtime |
| --- | --- | --- | --- |
| Бот тестера и владельца | `~/work/simple-chat-live-pace`, `4febee6` | 1 октября, 00:32:58 | Node 24.9.0 |
| Отдельный стенд Mini App владельца | `~/work/simple-chat-mini-app`, `7ad1afc` | 29 сентября, 22:32:12 | Node 24.9.0 |

У каждого процесса 177 прочитанных tracked-файлов исходников совпали с Git HEAD.
Fingerprint охватывает `local/`, `lib/`, `captioner/`, package-файлы и `tsconfig.json`.
Два незакоммиченных элемента checkout live-pace находятся вне этого fingerprint.
Наблюдение не доказывает байты, загруженные при старте, и не охватывает untracked-зависимости и launcher.

У обоих процессов рабочий каталог — `~/work/simple-chat`, хотя `local/main.ts` взят из соседнего worktree.
Штатный `loadConfig` объединяет `.env` рабочего каталога с унаследованным окружением.
При сборке кандидата этот каталог и разрешение путей к состоянию нужно сохранить;
смена cwd без явного переноса конфигурации может выбрать другую базу.

## Восстановленная конфигурация

Использован `loadConfig` из исходников соответствующего процесса. Наружу выводились только признаки
и количества. Это реконструкция с текущим `.env`, а не извлечение объекта конфигурации из памяти бота.
Mtime `.env` предшествует обоим запускам, но сам по себе не доказывает неизменность файла с того момента.

Совпавший публичный alias — `gemma-4-31b-heretic-nvfp4`; declaration модели находится в
[manifest simple-serving](../../simple-serving/card/manifest.env).
Загруженные веса, доступность модели, Telegram и Mini App через внешний адрес не проверялись.
Истории не открывались, поэтому выбранный темп отдельных историй неизвестен.

Последний `bot_ready` в техническом launcher-логе: 1 октября, 00:33:02 по Москве.
Событие не содержит SHA; в нём нельзя искать доказательство версии исходников.
Пакет аренды имеет свой `baseRevision=5b918bc` и проверенные 41 из 41 файлов manifest.
Это версия инфраструктуры аренды, не версия бота. Пакет сам не запускает бот.

## Состав следующего кандидата

Основа интеграции — `b877a84`. Источник продуктового backend — `c7f5533`,
галереи — отдельные commits `c9565e2` и `4febee6`.
Полные SHA зафиксированы в снимке. Root и live расходятся на 58 и 41 commits;
переносить изменения нужно связанными функциями с сохранением нынешнего root-кода.

| Блок | Состав и критерий сохранения |
| --- | --- |
| Память и text gateway | Сохранить root `generation.ts`, `memory.ts` и serving. Repair у root и live уже один Git blob; повторного переноса не требуется |
| Версии внешности | Функция уже есть в root; не переносить её повторно из старой ветки |
| G | Перенести вместе с label validation и fallback, сохранив индивидуальный допуск |
| Clothes | Перенести текущую обработку одежды и порядок references/current frame, сохранив индивидуальный допуск; `picture-clothes.ts` отсутствует в root |
| Pose sets | Перенести import, очередь загрузок, annotations, variants и удержание файлов; `referenceFiles()` должен учитывать `poseSet` |
| Mini App | Перенести backend, авторизацию, лимиты и gallery; затем отдельные swipe/preload commits |
| Темп | Сначала сохранить паритет с наблюдаемой live-версией, включая отдельный `f01a067` 5→15 минут и default Scene; качество Moment/Chapter ещё не принято |
| Picture gateway | Сохранить root adapter и fixes `506c756`/`192c6a7`, с прежним выключенным режимом |
| Общая библиотека | Сохранить root `Usage.reasoningTokens`, одновременно добавить необходимые pose-поля; целиком заменять live-файлом нельзя |

Faces, новые memory-гипотезы, budget/vision и автоматическое включение picture gateway не входят
в перенос продуктового паритета. Их статусы и проверки остаются отдельными решениями.

## Проверка кандидата

Сначала собрать кандидат и проверить существующими offline tests, TypeScript и синтетическими
G/clothes/pose/library/Mini App сценариями. Проверить clothes/reference parity, учёт references
и сохранение изоляции библиотек.
Обычная сборка не должна обращаться к данным читателей или запускать аренду.

После паритета выбрать одну гипотезу для дефекта темпа и сравнить её с зафиксированным baseline.
Прежний замер Moment 5 минут дал остановку перед выбором в 7 из 16 ходов;
Chapter решала за героя после 7 из 8 пользовательских ходов.
Этот результат нельзя переносить на изменённый Moment 15 минут как его измерение.
[Исходный протокол](../../simple-chat-live-pace/docs/telegram-ui.md#pace).
Применяются критерии и остановка цикла из [improve-loop](improve-loop.md#one-step).
Карточные проверки выполняются по [очереди](experiment-queue.md) после подготовки ограниченных заданий.
