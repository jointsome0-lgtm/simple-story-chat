## Что делать, по порядку

### 1. Влить в `colab` две потерянные записи

Запись O3 phase 2 с ветки `o3-card` (строка в `docs/improve-log.md` и раздел
`scene-thinking-card-2026-10-28` в `docs/knowledge/improve-runs.md`) и
`docs/knowledge/pov-stand-3-2026-10-28.md` с ветки `pov-stand-3`.
Код этих веток не переносить вслепую: сначала сравнить с тем, что уже есть в `colab`
(`--resume` пробы там уже есть). Коммит — по слову владельца.

Готово, когда в `colab` журнал показывает результат T-O3, а запись стенда открывается по ссылке.

### 2. Baseline темпа в нынешней конфигурации

Это измерение, а не шаг цикла: промпт не меняется.
Прежняя проба лежит в `~/simple-story-chat-runs/2026-09-29/pace/` (`probe.mts`, `notes.md` с критериями,
`dry-run.mts`); её код не читался. Нужно повторить её на модели тестера через simple-serving, класс `internal`,
с лимитом «Миг» 15 минут и нынешним сэмплингом, на синтетических историях, с тем же слепым судьёй и теми же
критериями, зафиксированными до данных.

До карты: скрипт, сухой прогон, оценка минут и единица работы. Запуск на Colab идёт по
`colab:docs/gpu.md` (правила 1–5: не больше 30 units в день, ревью плана у GPT-6.1 Terra на `xhigh`).

Готово, когда есть числа по тем же четырём показателям для «Миг» и «Глава» и видно, остался ли дефект.
Гипотезу для исправления выбирать только после этого и только если владелец возобновит цикл.

### 3. Lean frame для обычных кадров: подготовить решение

Сначала прочитать запись третьего стенда и выписать, что она говорит об обычном режиме.
Если данных хватает, принести владельцу вывод; если нет, предложить отдельный стенд с критерием до данных.
Сейчас lean frame только для POV по решению владельца от 30 октября, менять это без него нельзя.

### 4. Бюджет мысли — только на свободные минуты

Smoke бюджета идёт 5–10 минут по `thinking-budget.md`. Запускать, только если на карте после пунктов выше
остаётся время. По умолчанию thinking не включать: оба замера качества против, а в боте нет переключателя
для сцен (в `colab` в `config.ts`, `serving.ts` и `generation.ts` не найден).
